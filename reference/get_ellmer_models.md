# Get Ellmer Models

Get Ellmer Models

## Usage

``` r
get_ellmer_models(provider, api_key)
```

## Arguments

- provider:

  A character string indicating the model provider (e.g., "anthropic",
  "deepseek", "google_gemini", "ollama", "openai").

- api_key:

  A character string containing the API key or credentials used to query
  the provider.
